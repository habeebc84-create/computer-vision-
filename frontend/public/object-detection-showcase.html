Real-Time Object Detection Using YOLOv8 and Transfer Learning

Detect custom objects live from webcam and video using YOLOv8 and transfer learning

View Demo Architecture

Abstract

This project fine-tunes YOLOv8 on a custom annotated dataset to detect objects in webcam and video frames. The workflow combines LabelImg annotation, PyTorch training, and OpenCV inference to display each detection with a bounding box, a class label, and a confidence score.

YOLOv8 Transfer Learning

Fine-tune pretrained weights on custom classes.

LabelImg Annotation

Draw bounding boxes and export class labels.

PyTorch Training

Train over multiple epochs and evaluate the best checkpoint.

OpenCV Inference

Read video frames and draw model predictions.

Introduction and Problem Statement

Introduction

Classical methods use hand-crafted features that can struggle when lighting, viewpoint, scale, or background changes. Generic detectors cover fixed class lists, so a custom object may have no matching label.

Problem Statement

Training from scratch is costly because it requires a large labeled dataset, more computation, and longer training. The goal is to detect custom objects from webcam and video above 20 FPS by fine-tuning a pretrained YOLOv8 model.

    Model Training

    Train with PyTorch, fine-tune for multiple epochs, save best weights as best.pt, check mAP, tune the confidence threshold.

  3. Module 3

    Inference & Visualization

    OpenCV captures webcam or video frames and draws bounding boxes, class labels and confidence scores.

Conclusion

Fine-tuning YOLOv8 connects custom image annotation to webcam and video detection in a single workflow. The resulting model uses OpenCV to display boxes, class labels, and confidence scores, with the confidence threshold adjustable for the target setting.
